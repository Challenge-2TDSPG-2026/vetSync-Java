Autenticação

Funciona pra tutor, veterinário ou admin — o backend descobre o perfil pelo e-mail. As abas ao lado mudam sozinhas de acordo com quem logar.

POST /auth/login

POST /auth/registrar (público, só cria TUTOR)

GET /auth/me

Bootstrap do primeiro admin

Só funciona se ainda não existir nenhum admin no banco, e a chave precisa bater com ADMIN_BOOTSTRAP_KEY do ambiente. Depois disso, sempre 409.

POST /admins/bootstrap

A senha temporária vem na resposta ao lado — use pra logar na aba Autenticação.
